# XrayHub — матрица возможностей 0.3.4

| Возможность | Состояние | Примечания |
|---|---|---|
| Импорт профилей | Реализовано | VLESS, VMess, Trojan, Shadowsocks, Xray JSON, текстовые/Base64-подписки |
| DNS | Реализовано | Один IP; `8.8.8.8` по умолчанию; редактирование и сброс |
| Правила маршрутизации | Реализовано | Только домен и действие (прокси/напрямую/блокировать) |
| Пинг серверов | Реализовано | ICMP; TCP connect fallback с явной пометкой |
| Режимы | Частично | Прокси и экспериментальный Xray TUN |
| Сетевой стек | Ограничение текущего backend | В Xray TUN нет документированного переключателя system/gvisor/mixed |
| SOCKS5 | Реализовано | Локальный вход, опциональная авторизация, генерация credentials |
| Трей | Реализовано | Окно прячется в трей; восстановление, подключение к последнему профилю, выход |
| Уведомления | Реализовано | Встроенная панель главного окна; диалог импорта — только file picker |
| Темы | Реализовано | Тёмная/светлая |
| Дополнительные ядра | Не реализовано | Sing-box/Mihomo backend и другие протоколы — будущий отдельный этап |

Статус «Реализовано» отражает наличие кода, а не подтверждённую работу на всех сборках Windows. Требуется проверка GitHub Actions и тестирование на реальном подключении.
