# Получить готовый XrayHub.exe без установки SDK на свой компьютер

Файл `build.bat` предназначен только для локальной разработки. Для обычного использования SDK устанавливать не нужно: GitHub Actions собирает приложение на удалённом Windows-компьютере и публикует готовый ZIP.

## Один раз подготовить репозиторий

1. Создай пустой репозиторий на GitHub (можно Private).
2. Загрузи в него **все файлы и папки проекта**, включая скрытую папку `.github/workflows/build-windows.yml`. В корне репозитория должны лежать `XrayHub.csproj`, `MainWindow.xaml` и папка `Services`.
3. Убедись, что GitHub Actions разрешены для репозитория.

## Получить сборку

1. Открой вкладку **Actions** репозитория.
2. Выбери workflow **Build XrayHub (Windows x64)**.
3. Нажми **Run workflow** (при первом push в ветку `main` сборка также запускается автоматически).
4. Дождись зелёной галочки у запуска.
5. Внизу страницы запуска скачай artifact **XrayHub-Windows-x64**. Для версии 0.3.0 включены локальные флаги и новая маршрутизация.
6. Распакуй ZIP и запусти `XrayHub.exe`.

## Что попадает в готовый пакет

- `XrayHub.exe`, опубликованный как self-contained single-file app: .NET Runtime включён, отдельно ставить .NET не требуется.
- `core\xray.exe` и файлы официального Xray Core.
- `READ-ME-FIRST.txt`.

Workflow использует .NET SDK 10 только на временном сервере GitHub Actions, не на твоём компьютере. Xray Core скачивается на сервере сборки и проверяется по SHA-256 перед включением в пакет. Версия ядра закреплена в workflow, чтобы сборка была воспроизводимой.

## Ограничения

- Это способ собрать пакет без установки SDK на локальный ПК, но для первого раза нужен GitHub-репозиторий и доступ к Actions.
- XrayHub реализует только перечисленные в README функции. Это не полная замена V2RayTun: отсутствующие протоколы и системные функции перечислены в FEATURE_MATRIX.md.
- Текущий target — .NET 10. Официальная матрица Microsoft для Windows 10 ограничивает поддержку LTSC/Enterprise; обычная Windows 10 Home/Pro не входит в поддерживаемую матрицу .NET 10. Для такой Windows потребуется отдельная проверенная сборка под совместимую платформу.
