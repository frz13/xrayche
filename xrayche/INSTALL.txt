# XrayHub 0.3.7 — update instructions

1. Download and extract `XrayHub-0.3.7-update.zip`.
2. Open `https://github.com/frz13/xrayhubtest`.
3. Upload the extracted files to the repository root, preserving the `Models` and `Services` folders, and replace files when prompted.
4. Commit the changes.
5. Wait for the existing GitHub Actions workflow to finish and download the new artifact.

Do not delete or replace `.github/workflows/build-windows.yml`.

This update changes the in-app notification translations, dark DataGrid domain editor, configuration-list mouse-wheel scrolling, and application-wide hidden scrollbar presentation. It keeps the event-driven Windows proxy-conflict watcher and its persistent unresolved-conflict state.
