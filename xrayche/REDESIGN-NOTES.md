# Изменения XrayHub 0.3.0

- Удалены generic/workspace-подписи и временные preview-формулировки из пользовательского интерфейса.
- Флаги для основных стран упакованы как локальные PNG-ресурсы; региональные эмодзи не используются как текстовые замены.
- Флаги определяются по коду в начале/конце имени профиля, по ISO-флагу и по распространённым названиям стран.
- Режим подключения по умолчанию — «Прокси». Ручной выбор режима сохраняется немедленно и восстанавливается при следующем запуске.
- Вкладка Traffic сохраняет DNS, WFP, QUIC, private-network и YouTube-check preferences; XrayConfigBuilder применяет соответствующие настройки.
- Вкладка Routing хранит упорядоченные пользовательские правила для domain/IP/port/network и явное действие по умолчанию. Резервный маршрут добавляется явно, чтобы не зависеть от порядка outbounds в импортированном JSON.
- Поиск proxy outbound основан на протоколе и теге, чтобы не принять freedom/blackhole/DNS за серверный прокси.
- About — внутренняя вкладка главного окна.
- Установлен логотип XrayHub в качестве `ApplicationIcon` и `Window.Icon`.
- Остались известные ограничения: Hysteria2, AmneziaWG/WireGuard, MASQUE, маршруты по приложениям/процессам, статистика, latency/load balancing, tray и updater.
