# XrayHub — TUN startup recovery patch

Изменён только `MainWindow.xaml.cs`.

## Что изменено
При подключении в режиме TUN приложение теперь делает одну повторную попытку, если Xray завершился:
- прямо во время старта (ошибка раннего завершения процесса), или
- во время проверки выхода через SOCKS, когда процесс Xray уже завершился.

Перед повторным стартом приложение просит завершить/очистить предыдущий процесс и ждёт 3 секунды, чтобы драйвер TUN успел освободить адаптер. Повтор не выполняется, если Xray всё ещё работает; обычные ошибки прокси/сети не маскируются.

## Ограничения проверки
Это изменение направлено на восстановление после кратковременного сбоя создания TUN-адаптера, включая ошибку «файл уже существует» (`0xB7`). Оно не может гарантировать отсутствие любых сетевых обрывов и не исправит постоянную неисправность драйвера/Windows.

Архив содержит исходники, а не готовый Windows EXE. В текущей среде нет .NET SDK/Windows build runner, поэтому компиляция и запуск приложения не выполнялись. Проверь сборку через GitHub Actions перед заменой рабочего приложения.
